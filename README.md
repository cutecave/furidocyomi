# FuriDoc Yomi — 振り仮名フォント

振り仮名をグリフに焼き込んだフォントです。IVS（Ideographic Variation Sequence）で読みを選択します。
PowerPoint など ruby マークアップ非対応のソフトでも振り仮名を表示できます。

👉 [PowerPoint での使い方](https://furidoc.com/help/ppt-furigana.html)

## ダウンロード

[Releases](../../releases) から最新の `FuriDocYomi.ttf` をダウンロードできます。

| ファイル | 用途 |
|---------|------|
| `FuriDocYomi.ttf` | 横書き用 |
| `FuriDocYomi-Tate.ttf` | 縦書き用 |
| `ivs_manifest.json` | 漢字→読み→VS の対応表 |

## 仕組み

通常の ruby（`<ruby>漢<rt>かん</rt></ruby>`）はソフト側のマークアップ対応が必要です。
IVS フォントは「漢字＋読み」を一つのグリフに合成し、Unicode Variation Selector で切り替えます：

```
漢       → 通常の漢字グリフ
漢 + VS17 → 漢字グリフ＋上部に「かん」（読み index 0）
```

OpenType cmap format 14 に対応していれば（ほぼ全てのモダンソフトが対応）、
ruby 処理なしで振り仮名が自動表示されます。

## エンコーディング規則

各漢字は複数の読みを持ち、それぞれが Variation Selector に対応します：

| 読み index | VS 番号 | Unicode | 用途 |
|-----------|---------|---------|------|
| 0 | VS17 | U+E0100 | 第1の読み |
| 1 | VS18 | U+E0101 | 第2の読み |
| 2 | VS19 | U+E0102 | 第3の読み |
| ... | ... | ... | ... |
| N | VS(17+N) | U+E0100+N | 第Nの読み |

計算式：`VS codepoint = 0xE0100 + index`

### 例

「今」の場合（manifest での定義）：

```json
"今": { "こん": 0, "きん": 1, "いま": 2, "きょう[今日]": 3, "けさ[今朝]": 4, "ことし[今年]": 5 }
```

| 文字列 | 表示結果 |
|--------|---------|
| `今` | 通常の「今」（ruby なし） |
| `今` + U+E0100 | 今＋上部に「こん」 |
| `今` + U+E0102 | 今＋上部に「いま」 |
| `今` + U+E0103 + `日` | 今日＋上部に「きょう」（2字中央揃え） |

### JavaScript での使用

```js
const VS = (index) => String.fromCodePoint(0xE0100 + index);

'漢' + VS(0)           // → 漢(かん)
'今' + VS(3) + '日'     // → 今日(きょう)  熟字訓
'生' + VS(4) + 'まれる'  // → 生(うま)まれる
```

## Manifest 形式

`output/ivs_manifest.json` が IVS フォントの仕様書です：

```json
{
  "漢字": { "読み": index, ... },
  "今": { "こん": 0, "きん": 1, "いま": 2, "きょう[今日]": 3 },
  "大": { "だい": 0, "たい": 1, "おお": 2, "おとな[大人]": 3 }
}
```

### 読みの出典

| レイヤー | 形式 | 出典 | 説明 |
|---------|------|------|------|
| 字単位 | `"こん": 0` | KANJIDIC2 | 単字の音訓読み、元の順序を維持 |
| 活用形 | `"うり": N` | KANJIDIC2 送り仮名 | 五段動詞 5 段展開・一段動詞連用形・形容詞語幹 |
| 促音便 | `"いっ": N` | 自動生成 | ち/つ/く/き → っ（例：一(いち)→一(いっ)） |
| 熟字訓 | `"きょう[今日]": N` | 常用漢字表付表 | `[語]` 表記で複数字にまたがる読みを示す。span = 語の長さ |
| 連濁 | `"ごん": N` | 自動生成 | 清音→濁音（か→が、さ→ざ、た→だ、は→ば） |
| 半濁音 | `"ぽん": N` | 自動生成 | は行→ぱ行（は→ぱ、ひ→ぴ、ふ→ぷ、へ→ぺ、ほ→ぽ） |

### 安定性ルール

**一度割り当てた index は変更しません。** 新しい読みは末尾に追加のみ。

これにより、既にエンコードされた文書（PPT スライドなど）が、
読みを追加しても常に正しく表示されることを保証します。

## 熟字訓 Span

熟字訓は読みが複数の漢字にまたがるケースです（例：「今日 → きょう」）。

manifest では `[語]` で表記します：
- `"きょう[今日]"` → span = len("今日") = 2
- `"まじめ[真面目]"` → span = len("真面目") = 3

読みは最初の漢字のグリフに載せます。後続の漢字は読みなしで通常表示されます。

## 漢字の選定

**常用漢字 2,136 字**（2010 年内閣告示）を対象としています。

常用漢字は小中学校の教育課程で学ぶ漢字であり、FuriDoc の主要ユーザー（子どもの漢字学習を支援する保護者）が必要とする漢字を網羅します。表外漢字（旧字体、人名用漢字等）は対象外です。

漢字リスト：`data/joyo_kanji.txt`（学年別配列）

## 読みの選定

各漢字の読みは以下のパイプラインで生成します：

```
KANJIDIC2 音訓読み        基本読み（5,822）
    ↓
活用形展開               五段動詞 5 段・一段連用形・形容詞語幹（+8,993）
    ↓                    例：売(う)る → うら/うり/うる/うれ/うろ
促音便展開               ち/つ/く/き → っ（+1,024）
    ↓                    例：一(いち) → いっ
熟字訓                   常用漢字表付表の複数字読み（+221）
    ↓                    例：今日→きょう、大人→おとな
連濁展開                 語頭清音→濁音（+6,513）
    ↓                    例：人(ひと) → びと
半濁音展開               は行→ぱ行（+1,306）
                         例：分(ふん) → ぷん
```

**合計：20,915 読み**（2,136 漢字）

### 活用形展開の規則

| 条件 | 展開方法 | 例 |
|------|---------|-----|
| 五段動詞（送り仮名がう段 1 字） | う段→全 5 段（あいうえお） | 売.る → うら/うり/うる/うれ/うろ |
| 一段動詞（送り仮名が 2 字以上、末尾る） | 連用形（る除去） | 食.べる → たべ |
| 形容詞（送り仮名末尾い） | 語幹（い除去） | 美.しい → うつくし |

送り仮名データは KANJIDIC2 の nanori/okurigana フィールドから抽出しています。

### 連濁・半濁音展開の規則

既存の全読み（活用形・促音便含む）に対して、語頭の仮名を変換します：

| 変換 | 対象 | 例 |
|------|------|-----|
| 連濁 | か→が、さ→ざ、た→だ、は→ば | 方(かた) → がた |
| 半濁音 | は→ぱ、ひ→ぴ、ふ→ぷ、へ→ぺ、ほ→ぽ | 分(ふん) → ぷん |

### カバレッジ検証

NDL 振り仮名コーパス（青空文庫約 15,000 作品）の漢字読みペアとの照合結果：

| 指標 | 値 |
|------|-----|
| コーパス漢字数 | 5,482 |
| manifest 内漢字の加重カバレッジ | **97.62%**（出現頻度ベース） |
| 全漢字の加重カバレッジ | 92.54% |

「manifest 内漢字」は常用漢字 2,136 字のうちコーパスに出現したものです。加重カバレッジは出現頻度で重み付けしており、よく使う読みほど重視されます。

全漢字カバレッジが低いのは、コーパスに旧字体や表外漢字（云、廻、之 など）が多く含まれるためです。これらは常用漢字外のため、対象外としています。

残りの未カバー読みの多くはコーパスの文字分割アーティファクト（複合語の前綴が漢字に付着する等）であり、FuriDoc の実際のパイプライン（kuromoji + fitObj）では発生しません。

検証スクリプト：[furidoc/k2rw/check_coverage.mjs](https://github.com/cutecave/furidoc)
